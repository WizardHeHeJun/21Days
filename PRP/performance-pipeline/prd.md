# PRD: 演出管线（performance-pipeline）

> 日期：2026-09-26。用户诉求原文：「做一个演出管线，在一部分地方挂载这个演出，主要演出是一个简短的 Live2D 动画，
> 同时配套做一个演出动画编辑器，方便动画师制作动画。」
> 本会话自主运行，PRD 的「待确认问题」按下文默认值先做，用户可在验收时推翻（每条都标了改动代价）。

## 问题 / 动机

游戏是叙事冒险，剧情节点需要「一段短演出」：角色（Live2D 模型）做一段几秒到十几秒的表演，配字幕与音效，
播完回到探索或对白。现在整个工程没有「演出」这个概念——对白只会换立绘（roadmap D1–D3 全部待做），
关键剧情只能靠台词硬说。动画师这边更没有工具：Live2D 模型做完了也没地方摆、没地方排时间、没地方预览。

要解决的是两件事：**玩法侧一行调用就能在任何节点插一段演出**；**动画师不写代码就能做出并预览一段演出**。

## 目标（可度量）

- G1 任何模块（对白、场景物体、将来的剧情控制器）能按编号拉起一段演出，等它播完或被玩家跳过，拿到结果继续。
- G2 一段演出的内容（谁出场、什么表情、什么时候说什么字幕、什么时候等玩家点一下、配什么音效）
  由动画师在编辑器里可视化编排，不改代码、不改配置表。
- G3 至少两类挂载点可用：**场景里走到某处自动播**、**对白进行到某一句之前插播**。
- G4 演员可替换：占位演员（精灵图）与 Live2D 演员对管线一视同仁，换演员不改演出编排方式。
- G5 Live2D SDK 未导入时工程照常编译与运行；导入后不改代码即可用 Live2D 演员。

## 范围 / 非目标

**做**：

- 演出播放：暂停世界、收掉探索 HUD、黑边、字幕、「等待玩家确认」的停顿点、长按跳过、播完恢复现场并广播事件。
- 演出内容形态：一段演出 = 一个可编排的时间轴 + 出场的演员 + 字幕 / 表情 / 停顿点 / 音效轨道。
- 一次性演出：同一段演出「只播一次」可记进存档，重进不再播。
- 挂载点：场景触发区（走进去播）、场景加载即播、对白节点前插播。
- 编辑器：列出全部演出、一键新建（带默认轨道与登记）、打开时间轴编排与拖动预览、校验（缺演员 / 空字幕 / 表情名不存在 / 未登记）、运行时一键试播。
- Live2D 适配层：SDK 在时自动参与编译，表情按名字驱动，动作走 Live2D 导入产生的动画片段。
- 占位演员：用现有立绘精灵做一个示例演出，回放里看得见整条链路。

**不做**（明确留给后续或人做）：

- 下载 / 导入 Live2D Cubism SDK 与任何 Live2D 模型（授权协议要人点，SDK 与示例模型都不能进仓库）。
- 相机运镜系统、镜头语言预设（用时间轴自带的动画轨道即可满足首版）。
- 配音、口型、语音（设计支柱明确不做配音）。
- 演出中的分支选项、多段演出并行、演出内嵌对白。
- 演出中途存档 / 从中途恢复（演出期间不存档，重进从头播）。
- 手机端触屏专属操作（PC 优先，移植阶段再补）。

## 玩家故事 / 关键场景

- 作为玩家，我走进村口那片区域时，画面上下压出黑边，长者的 Live2D 立绘走进来叹了口气，字幕一句句出现，
  播完黑边收起，我继续走；再走进同一片区域不会再播。
- 作为玩家，我跟旅人对话到第二句时，先插入一段几秒钟的演出（他掏出地图指了指），播完对话框回来继续说。
- 作为玩家，演出里出现「▼」提示时我按确认键才继续；不想看时按住跳过键一秒钟直接结束。
- 作为动画师，我在菜单里新建「perf_village_intro」，拖进 Live2D 模型，在时间轴上摆动作片段、表情、字幕、停顿点，
  拖时间线就能看到效果，点「校验」没有红项，进 Play 点「试播」就能在游戏里看一遍。

## 验收标准

- [ ] A1 演出规则的阶段迁移、停顿点确认、长按跳过计时、重入拒绝、一次性记忆有 EditMode 测试且全绿。
- [ ] A2 回放：代码拉起示例演出 → 黑边出现、字幕依次显示、停顿点等确认后继续 → 结束后黑边收起、世界恢复、探索 HUD 与输入恢复（截图可见）。
- [ ] A3 回放：演出中长按跳过 → 提前结束，结果为「已跳过」。
- [ ] A4 回放：走进触发区自动播一次；再走进去不播。
- [ ] A5 回放：对白某一句前插播演出，演出期间对话框隐藏，播完对话框回来继续下一句。
- [ ] A6 编辑器：菜单能新建演出（预制体 + 时间轴 + 登记地址一步到位）；校验能列出缺项；模板工厂与校验器有 EditMode 测试。
- [ ] A7 Live2D 适配程序集在 SDK 缺席时不参与编译、控制台零错误；`invariants.py` 通过（asmdef 方向、命名空间、`.meta`）。
- [ ] A8 文档：模块三件套、策划 / 美术说明、开发者手册「Live2D 接入」一节、roadmap 状态回填。

## 涉及模块 / 依赖

- 新模块 `Game.Performance`（`Assets/_Project/Scripts/Runtime/Performance/`，在 `Game.Runtime` asmdef 内）。
- 新的可选程序集（Live2D 适配层），只在 SDK 存在时编译。
- 编辑器工具在 `Assets/_Project/Scripts/Editor/`。
- 修改 `Dialogue` 模块：对白节点加「插播演出」字段（配置表 schema + 数据 + 翻译 + 控制器）。
- 新增 ScriptableObject 配置（`Data/Performance/`）、演出预制体与时间轴资产、验证场景、UI 面板预制体、一个 Addressables 组。
- 外部包：`com.unity.timeline` 1.7.7（已在 manifest，尚未被工程代码引用）；Live2D Cubism SDK for Unity（**未导入**，人做）。
