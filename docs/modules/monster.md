# 怪物（Monster）

> 状态：可用　·　是否已接进游戏：已挂 Boot　·　程序文档：[三件套](../../ai-docs/docs/modules/monster/monster-module-guide.md)

## 1. 一句话

Monster 是探索场景里巡逻的敌人：沿固定路线走走停停，用“视野扇形 + 距离”察觉玩家，从起疑到敌对追击，最后可能出手攻击。
它是目前潜行、伪装玩法的对手，也负责把玩家从标题带进探索场景、管理这一整段遭遇的开始与结束。

## 2. 玩家看到什么、做什么

- 从标题点「开始」进入探索场景（SampleScene 灰盒地图），场景里有一个巡逻者（拼接小人造型）。
- 巡逻者沿场景里摆好的几个点依次循环行走，每走一阵会原地停一会儿。
- 玩家靠近时，巡逻者脚下的指示环变色表示态度：
  - 灰色：巡逻中，没发现玩家；
  - 橙色：警戒，起了疑心，会朝玩家走过来；
  - 红色：敌对，追着玩家跑并尝试攻击；
  - 黑色：被打倒。
- 左上角显示「怪物生命 N　状态 xxx」和一条警戒条（越满越接近敌对）。
- 视野扇形本身不画在画面上，玩家只能从颜色和警戒条判断。
- 玩家可以潜行绕背、开伪装混过去，或者正面用普通攻击把它打倒。
- 右上角「返回标题」随时离开遭遇。

## 3. 规则

**巡逻**
- 按场景里摆放巡逻点的顺序依次走，走到最后一个再回到第一个；只有一个点时就在原地附近巡逻。
- 连续走 7～10 秒（每次随机取整数秒）后原地停 2 秒，然后继续走。
- 警戒消退回巡逻时，从离自己最近的那个巡逻点接着走。

**感知（每一瞬间按以下优先级判定，前一条成立就不看后面）**
1. **红区**：玩家在正前方视野扇形内、距离 2 以内 → 立刻敌对。潜行、伪装都挡不住。
2. **橙区**：玩家在视野扇形内、距离 6 以内，且玩家**没有伪装** → 察觉。
3. **贴身**：玩家在视野之外（身侧或背后）、距离 1.5 以内，且玩家**没有潜行** → 察觉。
- 视野扇形总角度 75°（左右各 37.5°），红区与橙区半径比 1:3。
- 感知是纯距离与角度计算：墙、箱子等障碍物**不挡视线**。
- 玩家已死亡时怪物不再感知玩家。

**警戒与敌对**
- 察觉期间警戒值持续上涨，从零到满需要 4 秒连续暴露；满了即转敌对。
- 警戒状态下，只在还能察觉到玩家时朝玩家移动（速度为巡逻速度 × 1.1）；察觉不到就原地不动、警戒值开始回落。
- 警戒回落是先慢后快：从满值落到零需要 6 秒。落到零后回去巡逻。
- 敌对状态下朝“最后一次看到玩家的位置”追（速度为巡逻速度 × 1.25）。
- 敌对后连续 2 秒察觉不到玩家，降回警戒（警戒值满），再按上面的规则慢慢回落。
- 被玩家打中但没死，会立即转敌对，冲向玩家挨打时的位置。

**攻击与生命**
- 只有同时满足以下条件才会出手：处于敌对、此刻能察觉到玩家、玩家活着、玩家**没伪装**、距离 0.8 以内、攻击冷却已结束。
- 每次出手造成固定伤害，之后冷却 1 秒。
- 生命归零即倒下，不再移动或攻击，直到下次进入场景。
- 每次进入场景都重置：生命回满、站到第一个巡逻点、面朝第二个巡逻点、回到巡逻状态。

**其他**
- 对话、任务面板打开期间整个遭遇逻辑冻结，怪物不动也不涨警戒。
- 配置不合法（速度、半径、时间为 0 或负数；橙区半径不大于红区半径；视野角不在 0～360 之间；巡逻最长时间小于最短时间）时进入场景会直接报错。

## 4. 策划能改什么

所有字段都在 Inspector 里选 `Assets/_Project/Data/Monster/MonsterConfig.asset`。改法见 [策划手册第 3 章](../designer-guide.md#3-改数值两条路怎么选)，停止 Play 后再改，重新进场景生效。

| 想改什么 | 在哪改 | 字段 / 表 | 改了影响什么 | 备注 |
| --- | --- | --- | --- | --- |
| 巡逻速度 | `MonsterConfig.asset` | `Patrol Speed`（现值 2） | 巡逻快慢；也是警戒、敌对速度的基数 | 驯服后被控制时也用这个速度 |
| 警戒 / 敌对移速倍率 | 同上 | `Alert Speed Multiplier`（1.1）、`Hostile Speed Multiplier`（1.25） | 警戒时靠近、敌对时追击的快慢 | 敌对实际速度 2.5，玩家步行 3、奔跑 5 |
| 视野角度 | 同上 | `Vision Angle`（75°） | 扇形总开角，越大越难绕开 | 0～360 之间 |
| 橙区 / 红区半径 | 同上 | `Alert Radius`（6）、`Hostile Radius`（2） | 多远会起疑、多远直接敌对 | 橙区必须大于红区 |
| 贴身察觉半径 | 同上 | `Near Sense Radius`（1.5） | 从身侧、背后多近会被发现 | 潜行可免疫 |
| 警戒涨满 / 回落时间 | 同上 | `Alert Fill Seconds`（4）、`Alert Fall Seconds`（6） | 被看多久转敌对、脱离后多久消警戒 | 秒 |
| 敌对丢失目标时间 | 同上 | `Hostile Lose Seconds`（2） | 敌对后多久没看到才降为警戒 | 秒 |
| 巡逻停步节奏 | 同上 | `Patrol Min Seconds`（7）、`Patrol Max Seconds`（10）、`Patrol Pause Seconds`（2） | 走多久停一次、停多久 | 前两项是整数秒，随机取区间内的值 |
| 攻击距离 / 冷却 / 伤害 | 同上 | `Attack Range`（0.8）、`Attack Cooldown`（1 秒）、`Attack Damage`（1） | 怪物多近能打到玩家、多久打一次、一下扣多少 | 冷却是原型值，待试玩校准 |
| 怪物生命 | 同上 | `Max Health`（3） | 玩家要打几下 | 玩家伤害在 [player.md](player.md) |
| 巡逻路线 | 找程序或在场景里改 | 场景中遭遇视图上的巡逻点列表 | 巡逻路径与出生点 | 属于场景摆放，改前先和程序确认 |

怪物目前没有 Luban 配置表；所有怪物共用这一份配置，不能按个体区分数值。

## 5. 现在有的内容

- 一份配置资产 `MonsterConfig.asset`，数值见第 4 节。
- SampleScene 中一个巡逻者和它的巡逻点；另有 `MonsterEncounter.unity` 原型场景。

- 回放验证用例覆盖巡逻、警戒、追击、命中、死亡五个画面检查点。

## 6. 已知限制与还没做的

- **只有一个怪物、一种怪物**：没有多敌人、没有怪物种类表，数值不能按个体配置。
- **视线不被遮挡、没有寻路**：怪物直线走向目标，会被墙卡住；感知穿墙。
- **战斗结果没人接（C5）**：打倒怪物或玩家被打倒后，没有胜利 / 失败流程，也不会推进剧情。
- **战斗形态可能重做（G5）**：设计支柱倾向“追逐 / 躲藏 / 弱点识破”的无血条对抗，现有的攻击与生命规则待重新定义。
- **触屏操作（A5）**：延后到移动端移植阶段，旧的遭遇触屏按钮已移除。
- **标题入口是临时的（E2）**：标题「开始」直接进遭遇场景，主菜单做出来后要改走主菜单。
- **不存档（E1）**：遭遇状态有存档数据结构，但游戏里没有任何时机会真的保存。
- **没有正式美术（F3）**：怪物 / 妖灵造型、受击与攻击表现都没有，状态靠指示环颜色区分。

## 7. 和其他模块的关系

- [player.md](player.md)：读取玩家的位置、朝向、潜行、伪装、生命做感知判定；命中时扣玩家生命。遭遇开始时一并重置玩家。
- [disguise.md](disguise.md)：怪物出手前统一询问伪装规则，玩家伪装时一律不攻击。
- [taming.md](taming.md)：驯服验证场景里可以直接接管怪物移动，被控制时怪物不再自己思考。
- [characterpuppet.md](characterpuppet.md)：SampleScene 里巡逻者的走路 / 待机画面。
- [isometricexploration.md](isometricexploration.md)：相机跟随、2.5D 投影与贴地。
- [narrative.md](narrative.md)：将来剧情的“战斗阶段”要读取遭遇结果，目前未接。
- [dialogue.md](dialogue.md)、[quest.md](quest.md)：对话或任务面板打开时遭遇逻辑冻结。
