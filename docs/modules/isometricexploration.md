# 探索场景（IsometricExploration）

> 状态：原型　·　是否已接进游戏：已挂 Boot（探索 HUD 与沉浸模式）；相机跟随、纸片朝向为场景级组件　·　程序文档：[三件套](../../ai-docs/docs/modules/isometricexploration/isometricexploration-module-guide.md)

## 1. 一句话

把玩家带进一张 2.5D 探索地图：3D 灰盒环境 + 始终正对镜头的纸片角色，斜俯视镜头平滑跟着玩家走。
它是整个探索玩法的「舞台」，本身不管战斗和剧情；潜行、巡逻怪、对话、任务都在这张舞台上演。
另外负责探索时常驻的底部按钮，目前只有左下角的「沉浸」按钮。

## 2. 玩家看到什么、做什么

- **视角**：固定斜俯视，镜头俯角 38°、视野较窄（FOV 28），有近大远小的透视感，看起来像明日方舟活动地图那种「低模场景 + Q 版小人」。
- **镜头**：跟着玩家走，停下后会轻轻缓一下再定住；镜头角度和远近不变，不会自动转向或拉近拉远。
- **角色**：玩家和巡逻者都是拼接小人（见 [characterpuppet.md](characterpuppet.md)），永远正面朝镜头，往左走整体镜像朝左、往右走朝右；脚下有圆形影子和一圈状态指示环，头顶有名字牌（「玩家」「巡逻者」）。
- **地面**：走上台阶身体会跟着抬高、走回平地落回去；角色能被墙、塔、栏杆等灰盒物体挡住一部分。
- **操作**：键盘 WASD / 方向键、手柄左摇杆移动；左 Shift 潜行，左 Ctrl 切换散步 / 奔跑，G 伪装，J 攻击，空格 / 回车确认（和 NPC 对话）。按键归 [player.md](player.md) 与 [monster.md](monster.md) 管，这里只是舞台。
- **沉浸模式**：点左下角「沉浸」按钮，或按 H（手柄右摇杆按下），画面上的界面、NPC 头顶标记、对话气泡、任务标记全部隐去，只剩这个按钮（变成半透明的「退出沉浸」）。
- **画面风格**：暖色方向光从左上打下来，远处有淡淡的暖灰色雾，四角轻微压暗；高画质档有柔和阴影和环境遮蔽。

## 3. 规则

- 角色的位置只由遭遇规则（玩家 / 巡逻怪的逻辑）决定；场景里的墙和物体**只负责遮挡画面，不挡人**，角色可以穿过灰盒物体。
- 贴地是纯视觉：角色所在位置往下探测，落在 `Ground` 层的物体上就把身体放到它表面；单次抬升超过 0.32 就当作墙顶 / 家具，不贴上去。高度不影响任何玩法判定（警戒、攻击距离都不看高度）。
- 状态指示环的颜色（染在脚下圆环上，不染小人本身）：
  - 玩家：普通蓝、潜行青、伪装绿、死亡黑。
  - 巡逻者：巡逻灰、警戒橙、敌对红、死亡黑。
- 纸片朝向：按屏幕左右方向的移动来翻面；只上下走时保持原朝向。
- 沉浸模式：
  - 进入：沉浸按钮或 H 键；对话进行中按 H 无效（按钮不受此限）。
  - 退出：再点按钮 / 再按 H；沉浸中按取消键（Esc / 手柄 B）且没有对话在播时退出；一旦开始对话自动退出。
  - 被隐藏的界面只是看不见、点不到，不会关闭，退出后原样回来。
  - 角色头顶的名字牌目前**不**跟着隐藏。
- 镜头只跟位置：没有地图边界，走到地图边上镜头照样跟过去。
- 从标题「开始」进入这张场景；开发时也能直接在编辑器里播放它，两种方式玩法一致。

## 5. 现在有的内容

- **一张场景**：SampleScene，是目前唯一的探索场景。灰盒环境包含地面、后墙、左墙、塔、四级台阶、栏杆、三个路锥、两条长椅，全部是占位几何体。
- **两个角色**：玩家与巡逻者，都是占位拼接小人；另有 3 个 NPC 与 2 个任务地点（归 [dialogue.md](dialogue.md)、[quest.md](quest.md)）。
- **6 个旧的「室内」环境纸片**：已停用，保留在场景里备用。
- **光影基线**：方向光角度 (50, -35, 0)、暖白色、强度 1.15、柔和阴影；线性雾 18–42 米、暖灰色；环境光平光灰。
- **画质两档**：高档（电脑默认）柔和阴影、阴影距离 40、2 倍抗锯齿、环境遮蔽；手游档（安卓默认）硬阴影、阴影距离 25、无抗锯齿、无环境遮蔽。
- **探索 HUD**：左下角沉浸按钮已可用；右下角预留了一个空位，给后续的散步 / 奔跑按钮。
- **回放用例**：「潜行从背后接近 → 正面被发现 → 被追 → 近身打倒巡逻者」与「走上台阶身体抬高、回平地落回」两条，均通过。

## 6. 已知限制与还没做的

- 场景是占位灰盒，正式环境模型未做（roadmap F2）。
- 只有一张场景，没有传送和多场景流转（A4）。
- 镜头没有地图边界、跟随死区，进对话时也不切构图（A6）。
- 散步 / 奔跑：按键切换已在工作区接上，但右下角的切换按钮还没放（A1）。
- 沉浸模式已在工作区实现，roadmap 表里 A2 尚未改成「完成」；角色名字牌不随沉浸隐藏。
- 触屏摇杆与触屏按钮还没有正式 UI（A5）。
- 可交互物体只有 NPC 对话一种，物资箱等泛化交互未做（A3）；白盒版物资箱、万向标、重置进度正在 [探索层白盒 PRP](../../PRP/exploration-whitebox/prp.md) 里推进，尚未落地。
- 墙和物体不挡人、不挡视线；巡逻怪隔着墙也能看见玩家（归 Monster 模块，无视线遮挡）。
- 两个角色站在一起时名字牌会叠在一起。
- 没有音频（F4）。
- 手游档性能未在真机上测过。

## 7. 和其他模块的关系

- 依赖 [monster.md](monster.md)：遭遇规则推动玩家和巡逻者移动，并把逻辑位置投影到这张场景上、染状态环颜色。
- 依赖 [player.md](player.md)：玩家的移动速度、潜行、奔跑、伪装、攻击。
- 使用 [characterpuppet.md](characterpuppet.md)：角色外观由拼接小人显示。
- 与 [dialogue.md](dialogue.md) 配合：对话开始时自动退出沉浸；沉浸时对话标记与气泡隐藏。
- 与 [quest.md](quest.md) 配合：沉浸时任务地点标记隐藏。
