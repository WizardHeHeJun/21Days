# 玩家（Player）

> 状态：可用　·　是否已接进游戏：已挂 Boot　·　程序文档：[三件套](../../ai-docs/docs/modules/player/player-module-guide.md)

## 1. 一句话

Player 是玩家在探索场景里操控的那个角色的“规则身体”：走、跑、潜行、伪装、普通攻击、受伤和死亡都由它判定。
它本身不负责画面，画面上的小人由遭遇场景读它的状态来摆位置、换颜色；怪物也是读它的状态来决定有没有发现玩家。

## 2. 玩家看到什么、做什么

- 从标题点「开始」进入探索场景（当前就是 SampleScene 那张灰盒地图），玩家控制一个小人四处走。
- 操作（键鼠 / 手柄）：
  - 移动：WASD 或方向键 / 左摇杆。
  - 潜行：按住 Shift / 左肩键，松开即恢复。
  - 伪装：按一下 G / 北面按钮开启，再按一下关闭。
  - 普通攻击：按一下 J / 西面按钮。
  - 走 / 跑切换：按一下左 Ctrl / 按下左摇杆。
- 画面反馈目前全是占位：
  - 小人脚下的指示环按状态变色：普通蓝色、潜行青色、伪装绿色、死亡黑色。
  - 左上角一行文字显示「玩家生命 N　潜行 是/否　伪装 是/否」。
  - 右上角有「返回标题」按钮。
- 没有正式的受击、死亡、攻击动画，也没有死亡后的失败页面；生命归零后小人变黑、不能再动。
- 这是 PC 游戏，触屏操作延后到移动端移植阶段（见第 6 节）。

## 3. 规则

- **移动**：朝输入方向移动，斜向不会比直走快；角色朝向随移动方向改变，不动时保持上一次朝向。
- **三档速度**，优先级从高到低：
  - 按住潜行时一律按潜行速度走；
  - 否则如果奔跑模式开着，按奔跑速度；
  - 否则按步行速度。
- **走 / 跑切换**：按一下切换一次，长按也只算一次。按住潜行时奔跑模式不会被关掉，只是暂时按潜行速度走，松开潜行立刻恢复奔跑。
- **潜行**：按住才生效。潜行时怪物察觉不到身侧和背后贴身的玩家（详见 [monster.md](monster.md)），但正面近距离照样会被发现。
- **伪装**：按一下开、再按一下关，长按只算一次；攻击不会自动解除伪装。伪装期间怪物不会出手攻击，但仍可能警戒和追着走（详见 [disguise.md](disguise.md)）。
- **攻击**：
  - 按下那一刻出手一次，长按不会连发；
  - 出手后进入冷却，冷却没结束再按无效；
  - 命中条件：怪物在攻击距离内，且在玩家朝向的前半边（身后打不到）；
  - 命中造成固定伤害；被打的怪物会立刻转为敌对，扑向玩家当时的位置。
- **受伤与死亡**：怪物每次命中扣固定生命；生命最低到 0，归零即死亡。死亡后不能移动、不能攻击、不再受伤。
- **每次进入场景都重置**：生命回满、朝右、不潜行、不伪装、步行模式、攻击冷却清零。
- **暂停**：对话或任务面板打开期间，整个探索逻辑冻结，玩家和怪物都不动。
- **配置不合法时**：任何速度、攻击距离、生命、伤害填 0 或负数（攻击冷却可以填 0），进入场景时会直接报错，场景起不来。

## 4. 策划能改什么

| 想改什么 | 在哪改 | 字段 / 表 | 改了影响什么 | 备注 |
| --- | --- | --- | --- | --- |
| 步行速度 | Inspector 里选 `Assets/_Project/Data/Player/PlayerConfig.asset` | `Move Speed`（现值 3） | 不潜行、不奔跑时的移动快慢，单位：场景单位/秒 | 必须大于 0 |
| 潜行速度 | 同上 | `Sneak Speed`（现值 1.5） | 按住潜行时的移动快慢 | 必须大于 0 |
| 奔跑速度 | 同上 | `Run Speed`（现值 5） | 奔跑模式下的移动快慢 | 资产里还没写入这个字段，Inspector 显示的 5 是默认值；改一次保存后才真正写进资产 |
| 攻击距离 | 同上 | `Attack Range`（现值 1） | 玩家能打中多远的怪物 | 必须大于 0；怪物的攻击距离是另一份，见 [monster.md](monster.md) |
| 攻击冷却 | 同上 | `Attack Cooldown`（现值 0.6 秒） | 两次攻击之间最短间隔 | 可填 0；原型值，待试玩校准 |
| 玩家最大生命 | 同上 | `Max Health`（现值 3） | 能挨几下 | 整数，必须大于 0 |
| 玩家每次攻击伤害 | 同上 | `Attack Damage`（现值 1） | 打怪物一下扣多少 | 整数，必须大于 0；怪物生命在 `MonsterConfig.asset` |
| 按键绑定 | 找程序 | `Assets/_Project/Data/Input/GameInput.inputactions` | 各动作对应的键位 | 属于输入配置，不建议策划直接改 |

改法与注意事项见 [策划手册第 3 章「改数值：两条路怎么选」](../designer-guide.md#3-改数值两条路怎么选)：停止 Play 后再改资产，保存后重新进场景生效。
玩家没有 Luban 配置表。

## 5. 现在有的内容

- 一份配置资产 `PlayerConfig.asset`，数值见第 4 节，全部是原型值。
- 一个玩家角色：在 SampleScene 中由拼接小人（`player` 对象）表现。
- 验证用场景 `Assets/_Project/Scenes/Verify/Disguise.unity`、`Taming.unity` 里也有一个 XY 平面的占位玩家。
- 一套回放验证用例，覆盖移动、潜行、伪装、攻击、受伤等动作可见。

## 6. 已知限制与还没做的

- **走 / 跑切换（A1）**：键鼠左 Ctrl / 手柄左摇杆按下切换，三档速度已有；小人步频已按速度区分（走约 1.6 倍、跑约 2.65 倍）；屏幕上的走跑按钮与触屏切换延后到移动端移植。
- **触屏操作（A5）**：延后到移动端移植阶段，现阶段只做键鼠与手柄。
- **奔跑动画、转身、交互动作（D6）**：小人只有待机和走路。
- **死亡没有后果**：生命归零后没有失败页、没有重来流程；战斗结果目前没有任何系统接收（C5）。
- **不存档**：玩家状态不会写进存档，每次进场景重置；游戏级存档流程整体还没做（E1）。
- **没有背包、装备、成长（B1）**。
- **攻击与生命是否保留待定（G5）**：设计支柱倾向无血条对抗，现有的攻击、生命字段可能在“追逐 / 躲藏 / 识破”机制定义后重做。
- **伪装会发展成画皮面具（G2）**：获取、时长、冷却、被识破等都还没定义。

## 7. 和其他模块的关系

- [monster.md](monster.md)：怪物读取玩家的位置、朝向、潜行、伪装、生命来判定感知与攻击；双方的互相伤害也在那边的遭遇流程里结算。玩家进场景、离场景由怪物遭遇流程统一管理。
- [disguise.md](disguise.md)：伪装开关状态存在玩家身上，伪装生效后“敌人不许攻击”的规则在 Disguise 模块。
- [taming.md](taming.md)：驯服验证场景里借用玩家的移动；控制怪物期间玩家原地不动。
- [characterpuppet.md](characterpuppet.md)：SampleScene 里的小人画面由拼接小人模块播放待机 / 走路动画。
- [isometricexploration.md](isometricexploration.md)：负责相机跟随、纸片朝向与 2.5D 投影。
- [dialogue.md](dialogue.md)：对话进行中探索逻辑冻结，玩家不能移动。
