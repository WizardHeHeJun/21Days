# 拼接小人（CharacterPuppet）

> 状态：可用（美术为占位）　·　是否已接进游戏：场景级组件（SampleScene 的玩家与巡逻者）　·　程序文档：[三件套](../../ai-docs/docs/modules/characterpuppet/characterpuppet-module-guide.md)

## 1. 一句话

用 5 张分件图拼出一个明日方舟风格的 Q 版小人，会待机呼吸、会走路、会左右翻面。
它只是角色的「皮」：谁在推角色、为什么推，它一概不管，只看角色动了多少来决定演哪段动画。
不用 Spine / Live2D，用的是 Unity 自带的分件图 + 动画。

## 2. 玩家看到什么、做什么

- 角色站着不动时，小人轻轻呼吸：身体上下起伏、胸口微微胀缩、头和手臂小幅摆动（一轮 2 秒）。
- 角色一走起来就切到走路：双腿大幅前后摆、手臂与同侧腿反向摆、每步身体颠一下、上身略前倾（一轮 0.6 秒）。
- 走得快腿摆得快，走得慢腿摆得慢，但有上下限，不会快到抽搐或慢到像滑步。
- 往屏幕左边走整只小人镜像朝左，往右走朝右；只上下走时保持原来的朝向。
- 对话弹出时世界暂停，小人回到待机呼吸，不会定格，也不会原地踏步；对话结束后恢复。
- 玩家不直接操作小人；玩家操作的是角色（见 [player.md](player.md)），小人跟着演。

## 3. 规则

- **走 / 停判定**：每 0.1 秒看一次角色移动了多远，换算成速度。
  - 站着时，速度达到 0.15（单位 / 秒）才开始走。
  - 走着时，速度降到 0.05 及以下才停下。
  - 两个阈值之间保持原状态，防止慢慢挪动时在走和停之间来回闪。
- **走路快慢**：走路动画播放倍率 = 移动速度 × 0.8，再限制在 0.8 到 1.6 倍之间。按当前数值：
  - 潜行（1.5 / 秒）→ 1.2 倍；
  - 普通走路（3 / 秒）与奔跑（5 / 秒）都会顶到上限 1.6 倍，**两者步频看起来一样**。
- **待机与走路之间的切换**有 0.12 秒的过渡。起步 / 停步最多慢约 0.1 秒，肉眼基本察觉不到。
- **翻面**：探索场景里跟随角色原纸片的朝向（由遭遇规则按左右移动决定）；没有原纸片的场景（如验证场景）按屏幕左右方向的移动判断，左右速度不超过 0.01 时不翻。
- **翻面是整只镜像**：所有分件一起左右翻转，所以分件图必须左右对称。
- **暂停**：世界暂停期间强制待机，恢复后重新判断，不会把暂停期间的位移算成一次猛冲。
- 小人不参与任何玩法：不影响碰撞、警戒、攻击距离。状态颜色（潜行、敌对等）染在脚下圆环上，不染小人。

## 4. 策划 / 美术能改什么

| 想改什么 | 在哪改 | 字段 / 资产 | 改了影响什么 | 备注 |
| --- | --- | --- | --- | --- |
| 换小人外观 | `Assets/_Project/Art/Sprites/Characters/Puppet/` | `Puppet_Head.png` 56×48、`Puppet_Hair.png` 60×34、`Puppet_Torso.png` 34×40、`Puppet_Arm.png` 12×34、`Puppet_Leg.png` 14×34 | 玩家与巡逻者的外观 | 直接覆盖同名文件；PPU 100；规格见 [美术手册 3.3](../artist-guide.md) |
| 分件的关节点 | 每张图的 Sprite 设置里的 Pivot | 头 / 发 / 躯干：底边中点；臂 / 腿：顶边中点 | 动画绕哪里转 | 关节点错了，摆动会「脱臼」；换图后必须核对 |
| 分件尺寸 | 同上 | 可以变 | 各分件位置可能对不上 | 尺寸变了请程序微调预制体里的分件位置 |
| 角色配色 | 程序在预制体上改各分件颜色 | `Assets/_Project/Prefabs/Characters/ChibiPuppet_Player.prefab`、`ChibiPuppet_Patrol.prefab` | 衣服、头发、皮肤、裤子颜色 | 颜色是乘在白底图上的；两个预制体是独立的，要分别改 |
| 用彩色分件（不染色） | 出彩图 + 请程序把分件颜色改回白 | 同上 | 彩图原色直接显示 | 先跟程序说一声 |
| 起步 / 停步灵敏度 | Inspector 里选 `Assets/_Project/Data/CharacterPuppet/ChibiPuppetConfig.asset` | `Move Start Speed` 0.15、`Move Stop Speed` 0.05 | 慢速挪动时多早开始迈腿、多晚停下 | 停步值要小于起步值，否则会来回闪 |
| 判定间隔 | 同上 | `Sample Window` 0.1 秒 | 走 / 停判断的稳定度与反应速度 | 调小会让走路时闪回待机，不建议动 |
| 翻面灵敏度 | 同上 | `Facing Dead Zone` 0.01 | 多小的左右移动就翻面 | 只在验证场景这类「没有原纸片」的情况下生效；探索场景里不起作用 |
| 走路步频 | 同上 | `Walk Cycle Speed Per Unit` 0.8、`Walk Rate Min` 0.8、`Walk Rate Max` 1.6 | 不同速度下腿摆多快 | 想让奔跑步频快于普通走路，要调高上限或调低系数 |
| 动作幅度、节奏 | 找程序 | `Assets/_Project/Art/Animations/chr_chibi_idle.anim`、`chr_chibi_walk.anim`、`chr_chibi_puppet.controller` | 呼吸 / 走路的样子 | 换图时不要动这三个文件；加新动作也找程序 |

这些是 ScriptableObject 数值，改法（退出 Play 再改、改完保存）见 [策划手册第 3 章](../designer-guide.md)。

**美术换图注意事项**

- 染色区域画白 / 浅灰，描边和五官用深色；现在玩家的蓝衣、巡逻者的灰衣是同一套图染出来的。
- 五官要左右居中对称；左右臂共用一张 `Puppet_Arm.png`（右臂自动镜像），左右腿共用 `Puppet_Leg.png`。
- 叠放次序固定：腿在最后，然后躯干、手臂、头，头发在最前。
- 不改预制体里的节点名字和层级：动画是按节点名找分件的，改名不会报错，只会不动。
- 小人整体高约 1.6 个单位；画布放大时各张等比放大即可。
- 换完图请程序跑一次 `/verify-module CharacterPuppet`，看待机、左右走、翻面、停下的截图；再进 SampleScene 确认能被灰盒环境正确遮挡。

## 5. 现在有的内容

- **5 张占位分件图**：程序画的白底描边图，拼成 7 个分件（头、头发、躯干、左右臂、左右腿）。
- **2 段动画**：待机呼吸（2 秒一轮）、走路（0.6 秒一轮），一个动画控制器在两者之间切换。
- **2 个预制体**：
  - 玩家：棕发、肤色、蓝衣、深蓝裤。
  - 巡逻者：深灰发、肤色、灰衣、深蓝裤。
- **SampleScene**：玩家与巡逻者已换成小人，原来的整张纸片隐藏保留。
- **验证场景**：`Assets/_Project/Scenes/Verify/CharacterPuppet.unity`，一只小人按「站 2 秒 → 右走 → 左走 → 停下 → 模拟对话暂停」回放，检查动画与朝向，已通过。

## 6. 已知限制与还没做的

- 分件与配色全是占位，正式角色美术未出（roadmap F3）。
- 只有待机和走路：没有转身、奔跑、交互、攻击、受击动作（D6）；D6 依赖走跑切换（A1）和美术方案。
- 普通走路与奔跑的步频目前一样（都顶到上限），A1 要求的「按速度区分步频」需要调参或加奔跑动画。
- 分件是整块旋转，不是骨骼变形，关节处的接缝只能靠关节点位置和前后遮挡掩盖。
- 只能左右镜像，没有背面 / 侧面等多朝向。
- 所有 NPC、怪物如果也要用小人，得各自复制一份预制体改配色（两个预制体没有共享母版）。
- 战斗表现是否改用 Spine 尚未决定（roadmap 第 6 节风险 7）。

## 7. 和其他模块的关系

- 被 [isometricexploration.md](isometricexploration.md) 使用：在探索场景里作为玩家与巡逻者的外观，随纸片一起正对镜头、被灰盒遮挡。
- 跟随 [monster.md](monster.md) 的遭遇表现：朝向读取遭遇规则翻好的原纸片。
- 间接依赖 [player.md](player.md)：玩家移动速度决定小人走路步频。
- 与 [dialogue.md](dialogue.md) 配合：对话暂停世界时小人保持待机呼吸。
