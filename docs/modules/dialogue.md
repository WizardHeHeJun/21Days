# 对话（Dialogue）

> 状态：可用　·　是否已接进游戏：已挂 Boot　·　程序文档：[三件套](../../ai-docs/docs/modules/dialogue/dialogue-module-guide.md)

## 1. 一句话

玩家走近 NPC 就能拉起一段带立绘的剧情对话：逐字显示台词、左右两侧立绘、可带条件的分支选项，支持自动、倍速、跳过和历史回看。对话是目前推进剧情、交代任务的唯一手段，任务系统的「与某人对话」目标也靠它完成。没有对话树的路人 NPC 则只在头顶冒一句闲话气泡。

## 2. 玩家看到什么、做什么

- 探索时，范围内可交谈的 NPC 头顶有灰色「…」；离玩家最近的那个变成白色「!」并显示名字，同时屏幕底部居中出现一条交互提示「[E] 对话 · NPC 名」。
- 按交互键（E / F / 手柄 A）、鼠标点底部交互提示、或直接点 NPC，都能拉起对话。回车 / 空格（确认键）不再触发交互。
- 对话打开后**世界停住**：角色、怪物、计时都冻结，玩家不能移动；任务栏和任务指引暂时隐藏。
- 对话框里台词逐字打出。打字中连点三下直接显示整句；整句显示后点一下进入下一句。
- 说话的角色立绘正常亮度、原大，另一侧的立绘压暗并略微缩小（过渡约 0.15 秒）；旁白时两侧都压暗。立绘出场从屏幕外侧滑入淡入、被清掉时滑出淡出，同一侧换表情时新旧图交叉淡化。
- 对话框从下方滑入打开、滑出关闭；说话人换了时名字会轻轻「弹」一下；台词打到标点会稍停再继续。
- 对话框上有一排按钮：「LOG」看本段已说过的台词，「自动」让台词自己往下走，「x1 / x2 / x4」切倍速（同时加快打字和自动翻页），「跳过」先弹「是否跳过剧情？」确认。
- 跳过会一口气翻到下一个选项停下；选完后继续跳，直到下一个选项或对话结束。
- 遇到选项时，选项以竖排胶囊出现在右侧，可带小图标；条件不满足的选项要么不出现，要么置灰并写明原因。
- 键盘 / 手柄也能全程操作：空格 / 回车 / 手柄 A 等同点对话框（同样三连补全）；A / 手柄 Y 自动，S / 手柄 X 倍速，Ctrl / 手柄 RB 跳过，H / 手柄 LB 历史（再按一次或 Esc 关闭）。按钮文字后缀显示键位（如「自动 A」）。选项前带序号「1.」「2.」，按数字键 1–4 直接选；选项出现时默认选中第一个可选项，方向键切换、回车确认。选项显示期间空格 / 回车不会翻页。跳过确认弹窗默认选中「取消」，回车按选中项、Esc 等于取消。Esc 不会关掉对话。
- 对话结束后世界恢复、任务栏回来；如果这段对话是当前任务目标，任务随即推进。
- 路人 NPC（没有对话树）：交互时头顶冒一个气泡，逐字说一句闲话，停留几秒后淡出，**世界不停**。每次交互按顺序换下一句，说完一轮从头循环。

## 3. 规则

- 同一时间只能有一段对话；对话进行中所有 NPC 都不可交互。
- 可交互条件：玩家在 NPC 的交互半径内（三维直线距离），且 NPC 有对话树，或者没有对话树但写了闲话台词。半径填 0 表示不限距离。
- 多个 NPC 同时在范围内，只有最近的那个是焦点，交互键只对焦点生效。
- 对话进行中世界始终暂停，所有台词都要点击推进；表里的「阻塞」开关目前不起作用（见第 6 节）。
- 倍速和自动每段对话开始时都重置为 x1、关闭。
- 自动模式下，整句显示完后停留「自动间隔 ÷ 当前倍速」秒自动翻页。
- 三连点补全：打字过程中，相邻两次点击间隔不超过「连点窗口」才算连点，攒满规定次数就整句显示；超时从 1 重新计。
- 跳过一经确认，本段对话内不能撤销；取消确认则照常继续。跳过的台词也记入历史。
- 选项条件每 0.25 秒重新判断一次，玩家点选时再判断一次，不满足则不生效。
- 条件写法：外层是「任一组满足即可」，组内是「全部满足」；不写条件的选项永远可选。
- 表情找不到时退回角色默认表情；默认立绘也找不到就隐藏那一侧，对话照常进行。
- 选项图标加载失败只是不显示图标，不影响选择。
- 对话以任何方式结束（正常结束、跳过、选拒绝）都会通知任务系统，任务系统只看「哪段对话结束了」，不看选了什么结局。
- 历史记录最多保留 500 条（可调，见第 4 节）。
- 必须从 Boot 场景进入、在标题点「开始」才有对话；直接运行玩法场景时有对话树的 NPC 拉不起来，只有路人闲话气泡能用。

## 4. 策划能改什么

对话树与角色表的配置流程（改 JSON、生成、挂到 NPC、验证）写在 [策划手册第 11 章](../designer-guide.md#11-配一段对话)，生成步骤与出错排查同 [第 4 章](../designer-guide.md#4-改配置表的完整流程) 与第 8 章，这里不重复，只列「能改什么、改在哪、边界在哪」。

| 想改什么 | 在哪改 | 字段 / 表 | 改了影响什么 | 备注 |
| --- | --- | --- | --- | --- |
| 新增 / 修改一段对话 | [`Tables/Data/dialogue/`](../../Tables/Data/dialogue/) 下 `<编号>.json` | 对话树表 TbDialogue | 台词、分支、立绘站位、结局出口 | 改完必须跑「生成」；改已上线台词把该节点 `revision` +1 |
| 新增角色 / 表情 | [`Tables/Data/dialogue_character.json`](../../Tables/Data/dialogue_character.json) | 角色表 TbDialogueCharacter | 名字、默认表情、可用表情 | 立绘图片要美术放进来并登记资源地址，找程序或美术 |
| 某个 NPC 说哪段对话 | 场景里 NPC 物体的 `Dialogue Interactable` 组件 | Dialogue Id | 交互拉起哪棵树；填 0 = 路人只说闲话 | 改完保存场景 |
| NPC 头顶名字 | 同上 | Display Name | 焦点时头顶名字、闲话气泡里的名字 | 对话框里的名字取角色表，不取这里 |
| 交互距离 | 同上 | Interact Radius | 多近才能交谈；现场三个 NPC 都是 2（约一个多身位） | 0 = 不限距离 |
| 路人闲话 | 同上 | Bubble Lines | 每次交互按顺序说一句，循环 | 不进表、不参与本地化 |
| 闲话气泡节奏 | `Assets/_Project/Prefabs/World/DialogueSpeechBubble.prefab` | Characters Per Second / Hold Seconds / Fade Seconds | 逐字速度 30 字/秒、停留 4 秒、淡出 0.3 秒 | 改预制体影响所有路人 |
| 对话手感 | `Assets/_Project/Data/Dialogue/DialogueConfig.asset` | 见下方全局参数表 | 所有对话的打字速度、倍速、自动、连点 | 直接生效，不用生成 |

**对话树表 TbDialogue**：文件 `Tables/Data/dialogue/<编号>.json`，一个文件一棵树，文件名就是编号。**每个字段都必须写出来**，空的写 `""`、`[]`、`false`。

| 字段名 | 含义 | 取值 / 例子 |
| --- | --- | --- |
| `id` | 对话树编号，全表唯一，NPC 和任务都靠它引用 | 整数，与文件名一致，如 `1001` |
| `entry` | 从哪个节点开始 | 节点名，如 `"l1"` |
| `nodes` | 节点列表 | 见下表 |

每个节点：

| 字段名 | 含义 | 取值 / 例子 |
| --- | --- | --- |
| `id` | 节点名，同一棵树内唯一 | `"l1"`、`"c1"`、`"end_accepted"` |
| `revision` | 修订号，改已上线台词时 +1，旧存档与已读记录据此区分 | 填 `1`；填 0 按 1 处理 |
| `kind` | 节点类型 | `Line` 一句台词 / `Choice` 一组选项 / `End` 结束 |
| `speaker` | 说话角色，对应角色表的 `id` | `"elder"`；空串 = 旁白 |
| `speakerName` | 临时改对话框里的名字（如「？？？」） | 空串 = 用角色表显示名 |
| `side` | 立绘站哪边 | `Left` / `Right`，只有两个位置 |
| `expression` | 表情 | `"angry"`；空串 = 默认表情 |
| `clearOther` | 是否清掉另一侧的立绘 | `true` / `false`；旁白忽略 |
| `text` | 台词正文（`Choice` 节点是选项上方的提问） | 支持 TMP 富文本标签 |
| `next` | 下一个节点 | `Line` 必填；`Choice`、`End` 写 `""` |
| `outcome` | 结局出口码，程序据此决定后续 | 只在 `End` 填，如 `"Accepted"`；不同结局用不同 `End` |
| `blocking` | 预留：是否阻塞 | 一律填 `true`，目前不起作用 |
| `choices` | 选项列表 | 只有 `Choice` 填，其余写 `[]`；`Choice` 至少一项 |

每个选项：

| 字段名 | 含义 | 取值 / 例子 |
| --- | --- | --- |
| `id` | 选项名，同一节点内唯一 | `"accept"` |
| `text` | 选项文字 | `"行，我这就去给您找人。"` |
| `next` | 选后跳到哪个节点 | 与 `outcome` **恰好填一个**，另一个写 `""` |
| `outcome` | 选后直接结束，给出结局出口码 | 同上 |
| `hideWhenUnavailable` | 条件不满足时：`true` 不显示，`false` 置灰 | `true` / `false` |
| `unavailableReason` | 置灰时显示的原因 | `"你和这位老先生素不相识"` |
| `icon` | 选项左侧小图标的资源地址 | 现有 `Dialogue/ChoiceIcon_Go`、`Dialogue/ChoiceIcon_Leave`；无图标写 `""` |
| `anyOf` | 出现条件：外层任一组满足即可 | `[]` = 无条件；每组写 `{"all": [条件…]}`，组内全部满足 |

每个条件：`fact` 读哪条事实、`key` 标记名（只有 `StoryFlag` 用，其余写 `""`）、`expected` 期望为 `true` 还是 `false`。可用事实：`PlayerAlive` 玩家存活、`PlayerSneaking` 玩家潜行中、`PlayerDisguised` 玩家伪装中、`TargetAlive` 对象存活、`TargetHostile` 对象敌对、`TargetDetected` 对象发现了玩家、`StoryFlag` 某个剧情标记。要加新事实找程序。**注意**：这些事实目前全是固定假值（见第 6 节），配了也看不出区别。

**角色表 TbDialogueCharacter**：文件 `Tables/Data/dialogue_character.json`，一个文件放全部角色（数组）。

| 字段名 | 含义 | 取值 / 例子 |
| --- | --- | --- |
| `id` | 角色编号，节点的 `speaker` 引用它 | `"elder"` |
| `displayName` | 对话框里显示的名字 | `"老者"` |
| `defaultExpression` | 默认表情，必须是下面 `expressions` 里的一个 | `"default"` |
| `expressions` | 表情列表，每项 `id` 表情名 + `sprite` 立绘资源地址 | `{"id": "angry", "sprite": "Dialogue/Portrait_elder_angry"}` |

立绘地址约定为 `Dialogue/Portrait_<角色>_<表情>`，新图要美术放图并在资源系统登记，策划只改表里的地址。

**全局参数 `DialogueConfig.asset`**（Inspector 里悬停字段名有中文说明，改法见 [策划手册第 3 章](../designer-guide.md#3-改数值两条路怎么选)）：

| 想改什么 | 在哪改 | 字段 / 表 | 改了影响什么 | 备注 |
| --- | --- | --- | --- | --- |
| 打字速度 | `DialogueConfig.asset` | Characters Per Second | 当前 35 字/秒（x1 时） | 最小 1 |
| 历史上限 | 同上 | History Limit | 当前 500 条，超出丢最早的 | 最小 1 |
| 倍速档位 | 同上 | Speed Steps | 当前 1、2、4，按钮循环切换 | 不能留空，否则拉起对话时报错 |
| 连点几次补全 | 同上 | Reveal Tap Count | 当前 3 次 | 改成 1 = 点一下就补全 |
| 连点窗口 | 同上 | Tap Window Seconds | 当前 0.5 秒 | 最小 0.05 |
| 自动翻页间隔 | 同上 | Auto Advance Seconds | 当前 1.5 秒（x1 时） | 会被倍速除 |
| 标点停顿 | 同上 | Punctuation Pause Seconds | 当前 0.12 秒（x1 时）：打出标点后停一下再继续 | 会被倍速除；连续标点（「……」「！？」）只停一次，句末标点不停；0 = 不停 |
| 哪些字算标点 | 同上 | Punctuation Chars | 当前 `，。！？…；：、,.!?` | 留空 = 不停顿 |
| 立绘入场 / 退场 | 同上 | Portrait Slide Distance / Portrait Slide Seconds | 当前从外侧滑进 80 像素、0.25 秒，同时淡入；清槽时反向滑出淡出 | 左边从左进出、右边从右进出；时长 0 = 直接出现 |
| 换表情的过渡 | 同上 | Portrait Crossfade Seconds | 当前 0.15 秒，新旧表情交叉淡化 | 0 = 直接换图 |
| 非说话者压暗 | 同上 | Portrait Dim Color / Portrait Dim Scale / Portrait Dim Seconds | 当前压到偏冷灰 (0.55, 0.55, 0.6)、缩到 0.96 倍，0.15 秒过渡；说话者原色原大 | 旁白（`speaker` 为空）时两侧都压暗；颜色只看 RGB |
| 名牌切换 | 同上 | Name Tag Punch Seconds / Name Tag Punch Scale | 说话人换了时名字从 1.15 倍 + 透明回落，0.15 秒 | 同一人连说两句不动；0 = 不做 |

## 5. 现在有的内容

- 对话树 2 棵、共 12 个节点：
  - `1001`（挂在 SampleScene 的「老者」）：老者抱怨村里人都跑光了，旅人询问，老者要人帮忙；三个选项「行，我这就去给您找人」（出口 `Accepted`）、「这事跟我可没关系」（出口 `Refused`）、「老先生，是我啊，您不记得了？」（要求剧情标记 `knows_elder`，当前永远隐藏，出口 `Accepted`）。
  - `1002`（挂在 SampleScene 的「旅人」）：旅人先搭话「这一路走来连个人影都没碰见，你也是被老先生支来的？」，接着提营地落脚、约天亮去瞭望点看看，两句台词后结束，出口 `Done`。
- 角色 2 个：`elder` 老者（表情 default、angry）、`traveler` 旅人（表情 default、smile）。立绘全是占位图。
- 选项图标 2 个（前往、离开），占位图。
- 路人 1 个：SampleScene 的「村民」，没有对话树，两句闲话「这个移动平台比我年轻时见到的老不少。」「今天的风有点大，小心站稳。」
- 另有独立验证场景 `Assets/_Project/Scenes/Verify/Dialogue.unity`，内容同上三人。

## 6. 已知限制与还没做的

- 选项条件的事实全是固定值（玩家存活、未潜行、未伪装、对象存活不敌对未发现、没有任何剧情标记），所以依赖剧情标记的选项永远不可用、依赖潜行 / 伪装的条件也不会变化。要等叙事接线（roadmap C1、C2）。
- 对话结束后的出口码（如 `Accepted` / `Refused`）目前没有任何玩法去读，选哪个结局对后续没有影响；由叙事模块接手（roadmap C1）。
- 不会自动触发对话（例如走进某区域、被怪物发现），只能玩家主动交互（roadmap C1）。
- 同一个 NPC 永远说同一棵树，不会随任务或剧情阶段换台词（roadmap C1、C3）。
- 「非阻塞旁白」（世界不停、边走边说）未实现，`blocking` 字段填什么都一样。
- 对话进度与已读记录不存盘：关游戏就清空；中途存读档也没有接（roadmap E1）。
- 跳过确认后不能撤销；已读 / 未读不影响能否跳过。
- 交互提示的键位徽章固定显示键盘键位（取交互动作第一条键盘绑定，现为「E」）；用手柄玩也不会换成手柄按键图标。
- 路人闲话写在场景里，不进表、不参与本地化。
- 没有全屏插图演出节点（roadmap D3）。立绘动效（D1）与对话框开合 / 名牌 / 标点停顿（D2）已做，待视觉验收。
- 所有美术（立绘、对话框、气泡、标记、图标）是占位（roadmap F3）；剧本量只有 12 个节点（roadmap F1）。
- 交互焦点、头顶标记这套只属于对话，宝箱等其他可交互物还用不了（roadmap A3）。
- 键盘 / 手柄按钮上的键位提示只显示键盘键位（取动作第一条键盘绑定）；用手柄玩也不会换成手柄按键图标。数字键只能选前 4 个选项。

## 7. 和其他模块的关系

- 被 [任务](quest.md) 使用：对话结束推进「与某人对话」目标；任务指引按对话编号找到 NPC；对话期间任务栏和指引隐藏。
- 依赖 [叙事阶段](narrative.md) 的条件写法：选项条件的事实种类与叙事模块共用一套；将来由叙事模块决定何时自动拉起哪段对话、提供真实的剧情标记。
- 与 [探索表现](isometricexploration.md) 配合：NPC 头顶标记与名字朝向相机；沉浸模式（隐藏 HUD）时头顶标记、气泡一并隐藏，对话拉起时退出沉浸。
- 与 [拼接小人](characterpuppet.md) 配合：对话时停期间角色回到待机呼吸。
